# ВТБ Ко-пилот: Интеллектуальный ассистент и тренажер бэк-офиса

**Спринт №1 (MVP)** — Прототип системы интеллектуальной маршрутизации, строгой регламентной поддержки решений (Strict Grounding) и интерактивного тренажера-песочницы для обучения стажеров бэк-офиса банка ВТБ.

---

├── backend/                       # Серверная часть (Go 1.27+, порт 8000)

## 🐳 Запуск через Docker (рекомендуется)

Нужен Docker с Compose v2 или новее (например, Docker Desktop). Go и Node.js на хосте не нужны.
Из корня репозитория:

```sh
docker compose up -d --build --wait
```

Интерфейс: [http://localhost:8080](http://localhost:8080).
При запуске на сервере замените `localhost` его IP-адресом или именем.
API доступен через тот же адрес: [демо-кейсы](http://localhost:8080/api/v1/cases),
[проверка API](http://localhost:8080/api/health).

Compose собирает Go API с демо-данными и React-интерфейс, который раздается через Nginx.
Nginx проксирует `/api/` в бэкенд; порт бэкенда наружу не публикуется.
Для текущего MVP внешние LLM, ключи API и отдельная база данных не нужны.
Первая сборка требует доступа к реестрам Docker, Go и npm; готовые образы работают без них.

```sh
docker compose ps                # состояние и healthcheck
docker compose logs -f          # логи (Ctrl+C — выйти из просмотра)
docker compose down             # остановка и удаление контейнеров
docker compose up -d --build --wait  # пересобрать после изменений кода или data/
```

Чтобы изменить внешний порт, создайте в корне файл `.env` со строкой `APP_PORT=3000`
и запустите ту же команду. Тогда интерфейс будет доступен на `http://localhost:3000`.

## 🚀 Локальный запуск без Docker (Windows PowerShell)

### 1. Запуск Backend (Go, порт 8000)

```powershell
# Переход в директорию бэкенда
cd backend

# Сборка бинарника
go build -o api.exe ./cmd/api

# Запуск сервера
.\api.exe
# (или напрямую через go run ./cmd/api)
```

* Healthcheck: [http://localhost:8000/](http://localhost:8000/)
* Демо-кейсы: [http://localhost:8000/api/v1/cases](http://localhost:8000/api/v1/cases)

---

### 2. Запуск Frontend (React + Vite, порт 5173)

В отдельном окне терминала PowerShell:

```powershell
# Переход в директорию фронтенда
cd frontend

# Установка зависимостей (уже выполнены в MVP)
npm install

# Запуск dev-сервера Vite
npm run dev
```

* Интерфейс доступен по адресу: [http://localhost:5173](http://localhost:5173)

## 🎯 Основной функционал

### 1. Боевой режим (Ко-пилот бэк-офиса)
* **Интеллектуальная маршрутизация**: Определение подразделения и уровня ответственности (L1, L2, L3) на основе регламентных признаков.
* **Черновик регламентной резолюции**: Генерация готового решения инцидента с пошаговым алгоритмом и указанием сроков SLA.
* **Strict Grounding**: Каждое действие подтверждается точной цитатой и пунктом нормативно-правового документа (регламенты REG-01, REG-02, 161-ФЗ, 762-П Банка России).
* **Индикатор уверенности (Confidence Score)**: Оценка надежности сформированного ответа и автоматический триггер эскалации на уровень L3 при нестандартных ситуациях.

### 2. Песочница стажера
* **Интерактивный тренажер**: Проверка решений стажеров по реальным инцидентам бэк-офиса.
* **Оценка по 10-балльной шкале**: Быстрый вердикт ("Успешно", "Требует доработки", "Не пройдено").
* **Разбор ошибок наставником**: Подробный анализ нарушений протоколов идентификации, правил СБП и кредитной политики.
* **Упущенные регламенты**: Четкий список нарушенных или забытых пунктов правил.
* **Эталонное решение**: Демонстрация стандарта работы банка ВТБ для закрепления знаний.
